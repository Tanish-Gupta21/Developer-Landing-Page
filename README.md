# Developer Landing Page

A modern and responsive developer landing page built using HTML and CSS. 
This project showcases my profile, skills, services, and contact information 
in a clean and simple layout.

##  Live Demo

[View Live Website](https://tanish-gupta21.github.io/Developer-Landing-Page/)

##  Technologies Used

- HTML5
- CSS3

##  Features

- Responsive developer landing page
- Hero section with developer introduction
- Web Development, App Development, and UI/UX sections
- About Me section
- Contact section
- Clean and simple user interface
- Image-based service cards
